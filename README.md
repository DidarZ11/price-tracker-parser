# Price Tracker Parser

Асинхронный трекер цен: собирает цены товаров с публичных сайтов, хранит историю
и присылает уведомление в Telegram, когда цена меняется.

## Возможности
- Асинхронные запросы (aiohttp) — высокая скорость
- Семафор для ограничения конкурентности
- Таймауты и обработка ошибок на уровне запроса
- История цен в SQLite — каждая проверка сохраняется
- Уведомления в Telegram об изменении цены (📉/📈 и процент) + `products.csv` файлом
- Периодический запуск: `--every N` — проверка каждые N минут
- Экспорт последней проверки в CSV
- Пример на books.toscrape.com (легальная тестовая площадка для скрейпинга)

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # и вписать BOT_TOKEN от @BotFather
python parser.py              # одна проверка
python parser.py --every 60   # проверять каждый час
```

Бот в Telegram не может писать первым: напиши ему `/start` перед первым запуском.
`CHAT_ID` подхватится автоматически и сохранится в `.env`.
Без `BOT_TOKEN` парсер работает, просто без уведомлений.

Результат: история в `prices.db`, последняя проверка в `products.csv`.

## Архитектура
- `Parser` — класс с настраиваемой конкурентностью (`concurrency`) и таймаутом
- `Product` — датакласс для типизированного результата
- `fetch()` — асинхронный HTTP-клиент под семафором
- `parse_book()` — извлечение данных через BeautifulSoup
- `track()` — сравнение с последней сохранённой ценой
- `PriceStorage` (`storage.py`) — история цен в SQLite
- `TelegramNotifier` (`notifier.py`) — отправка отчёта через Telegram Bot API
- `save_csv()` — сериализация в CSV

## Расширение под другие сайты
Переопредели метод `parse_book()` под нужный HTML-шаблон целевого сайта.
Структура `Product` при этом не меняется — остаётся единый формат вывода.

## Стек
- Python 3.11+
- aiohttp (async HTTP, Telegram Bot API)
- BeautifulSoup4 (HTML-парсинг)
- SQLite (история цен)
- python-dotenv (секреты в `.env`)
